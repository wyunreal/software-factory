Tailscale Funnel target on the k3s host:

  http://127.0.0.1:{{ .Values.web.tailscaleFunnel.nodePort }}/api/github/webhook

Configure it with the helper from the repository root:

  ./scripts/enable-tailscale-funnel.sh <REMOTE_USER> <REMOTE_HOST>

Or run the Funnel command directly on the k3s host:

  sudo tailscale funnel --bg --https=8443 \
    --set-path=/api/github/webhook \
    http://127.0.0.1:{{ .Values.web.tailscaleFunnel.nodePort }}/api/github/webhook

The public URL uses port 8443 because 443 is already used by other host
services. Then point the GitHub App webhook at
https://<host>.<tailnet>.ts.net:8443/api/github/webhook. Only that path is
mounted; do not forward the NodePort from the router.
{{- end }}

Only the webapp is exposed. The factory API, OpenCode runtime and PostgreSQL
are ClusterIP services and are not reachable from outside the cluster.

Check the rollout:

  kubectl -n {{ .Release.Namespace }} get pods,svc,ingress,certificate

Follow the logs:

  kubectl -n {{ .Release.Namespace }} logs -f deploy/{{ include "software-factory.fullname" . }}-factory
  kubectl -n {{ .Release.Namespace }} logs -f deploy/{{ include "software-factory.fullname" . }}-opencode
  kubectl -n {{ .Release.Namespace }} logs -f deploy/{{ include "software-factory.fullname" . }}-web

The TLS certificate is issued by cert-manager with the ClusterIssuer
letsencrypt-prod (DNS-01 via the Porkbun webhook). The DNS A record for
{{ .Values.ingress.host }} must point at the Traefik address of the cluster.
